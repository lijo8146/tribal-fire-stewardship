# Relationship to the sandbox

This repository is a smaller, independent first release.                             

| Sandbox theme | Treatment in this release |
|---|---|
| Historical fire | Rebuilt as four regional context examples from a hashed MTBS snapshot; no cross-Nation ranking |
| Indigenous stewardship | Rebuilt as separate, source-backed cases and partner-defined questions; no synthetic vegetation or cultural-fire opportunity score |
| Community assets/jurisdiction | Addressed as research-design and authority questions; no cultural-site locations or jurisdiction determinations |
| Cross-Tribal collaboration | Reframed as invited exchange; ecological proximity does not establish willingness to collaborate |
| Monitoring/smoke/watersheds | A tested observation workflow and prompts; future data modules depend on partner questions |
| Fire-weather and fire-speed prototypes | Reserved for a future retrospective research track; no operational predictions in this release |
